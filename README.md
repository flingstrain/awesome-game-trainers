# Awesome Game Trainers [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of resources for **PC game trainers** — where to find them, how they work, and how they differ from cheat tables.

A game **trainer** is a small program that toggles cheats (god mode, unlimited resources, etc.) in **single-player** PC games. This list collects the best trainer directories, the tools behind them, and guides.

**Single-player / offline use only.**

## What Is a Trainer?

A trainer runs alongside a game and flips cheat options on/off with hotkeys — no scripting required, unlike a raw memory editor. Trainers are made by tools such as WeMod, MrAntiFun, and the FLiNG trainer engine.

## Trainer Directories

Sites that publish and organize trainers by game:

- [FLiNGTrainer.us](https://flingtrainer.us/) — large, updated library of FLiNG-style trainers organized by game (e.g. `flingtrainer.us/<game>-trainer/`), with real option lists where available.
- [WeMod](https://www.wemod.com/) — desktop trainer app with a big catalog.
- [MrAntiFun](https://mrantifun.net/) — long-running trainer community.

## Trainer Engines & Tools

- [Cheat Engine](https://www.cheatengine.org/) — the memory editor many trainers/tables are built on.
- [ct-launcher](https://github.com/softwusa/ct-launcher) — CLI to index/open local `.CT` tables (companion repo).

## Trainer vs. Cheat Table

| | Trainer | Cheat Table (`.CT`) |
|---|---|---|
| Format | standalone `.exe` | script loaded in Cheat Engine |
| Ease | one-click hotkeys | attach + tick options |
| Flexibility | fixed options | editable, more advanced |

Both do the same job — enable single-player cheats. A trainer is a packaged front-end; a cheat table is the underlying script. For tables, see the sister list [awesome-cheat-engine-tables](https://github.com/softwusa/awesome-cheat-engine-tables).

## Safety

- Antivirus may flag trainers as a **false positive** (memory editing looks like malware behavior). Only download from trusted sources; back up saves.
- Never use in online/multiplayer — risk of bans.
