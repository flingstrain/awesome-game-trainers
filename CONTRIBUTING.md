# Contributing

Thanks for helping keep this list useful.

## What belongs here

An entry should be a resource a reader would actually open twice:

- **Trainer directories** that organise trainers by game and keep them current.
- **Tools and engines** used to build or run trainers.
- **Guides** that explain how trainers work, how to load them, or how to stay safe.

Every entry must be for **single-player / offline** use. This list does not accept anything
aimed at online or multiplayer cheating.

## What does not belong here

- Link shorteners, redirect pages, or sites that gate the resource behind surveys.
- Sites distributing pirated games. This list covers cheats, not piracy.
- Mirrors and clones of a resource already listed — link the original.
- Pages with no content beyond a download button.

## Entry format

One line per entry, alphabetical within its section:

```markdown
- [Name](https://example.com/) — what it is, in one short sentence.
```

Keep the description factual and under about 15 words. No marketing language, no
superlatives, no "best".

## Before opening a pull request

1. Check the link resolves and is not a redirect chain.
2. Confirm the resource is still maintained — a directory that stopped updating two years
   ago is not useful.
3. Add the entry to the right section, keeping alphabetical order.
4. One entry per pull request where practical; it makes review and discussion easier.

## Disclosure

If you are affiliated with a resource you are submitting, say so in the pull request. It is
not disqualifying — undisclosed self-promotion is.
